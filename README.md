# Modelo-CIFAR-10
Este repositorio contiene un proyecto de procesamiento de imágenes que evalúa diferentes filtros de detección de bordes (Sobel, Laplaciano, Canny, Prewitt y Scharr) aplicados a conjuntos de datos como CIFAR-10. El objetivo es analizar su rendimiento, ventajas y limitaciones para tareas de visión por computadora.
